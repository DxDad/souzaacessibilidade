# Souza Acessibilidade

Site profissional de Danilo Souza, publicado em `souzaacessibilidade.com.br`.

## Estrutura

Site estático em HTML, CSS e JavaScript, hospedado via GitHub Pages.

## Desenvolvimento

Os arquivos podem ser publicados diretamente a partir da raiz da branch `main`. O domínio personalizado é definido pelo arquivo `CNAME`.

## Acessibilidade

O projeto considera WCAG 2.2 e ABNT NBR 17225:2025 como referências principais para web, além de princípios aplicáveis da ABNT NBR 17060:2022 na experiência móvel.
